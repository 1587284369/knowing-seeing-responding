# data · 论文用的冻结数据快照

这是 v1 的冻结快照，从游戏项目 `06-游戏自动化/NEEDY-GIRL-OVERDOSE/log/` 复制出来的**只读快照**，
对应论文 v1（24 局、5 天）所统计的那 5 天（2026-10-20 19:46 → 2026-10-25 20:38）。

## 为什么冻结

论文数据写完后，游戏项目仍在继续被游玩（2026-10-26 03:46 又出现了新的 `play-*.png` 与日志行）。
若脚本直接读实时日志，重跑一次数字就会变，论文与报告对不上。
所以统计与绘图脚本**优先读本目录**；只有本目录不存在时才回退到游戏项目。

- `actions.log` 与 `daybook.csv` 里含中文路径与 `-1` 哨兵，均按 UTF-8 保存。
- 截图本体（5,450 张 PNG）体积大，未复制；论文只用到「截图事件数 13,686 / 唯一文件 5,389」这两个从日志推出的量。

- 若要刷新快照（例如把新的一局纳入研究）：重新截断 → 更新本文件的 MD5 与行数 → **同步改论文里所有受影响的数字**，不要只改一边。
